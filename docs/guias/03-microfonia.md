# Guia Rápido — Eliminar Microfonia (Feedback)

## O que é microfonia?

É aquele **apito agudo** que aparece quando o microfone capta o som da caixa de som.

## Passo a passo

### 1. Prevenção

- Microfone **atrás** das caixas de som (nunca na frente).
- Aponte o microfone **para a boca**, não para a caixa.
- Mantenha o volume do retorno o mais baixo possível.

### 2. Quando aparecer

1. **Reduza o volume** do canal que está microfonando.
2. No SoundAssist, o **Detector de Feedback** mostra a frequência exata.
3. Ative **Auto-Cut** para cortar automaticamente.
4. Ou use o botão **Cortar Frequência** manualmente.

### 3. Depois do evento

- Use **RT60** para medir a acústica da sala.
- Use **Auto-EQ** para equalizar o sistema e evitar feedback futuro.

## Lembrete

> Microfonia é sinal de que algo está muito alto. Sempre reduza o volume primeiro.
