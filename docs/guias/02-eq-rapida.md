# Guia Rápido — Equalização (EQ)

## Para que serve o EQ?

O EQ ajusta o tom do som: graves, médios e agudos.

## Ajustes Comuns

| Problema | O que fazer |
|----------|-------------|
| Voz abafada | Aumente 3-5 kHz |
| Voz fina/estridente | Reduza 3-5 kHz |
| Som "muito grave" | Reduza 80-200 Hz |
| Som "muito agudo" | Reduza 8-12 kHz |
| Microfonia aguda | Corte a frequência exata |

## Como usar no SoundAssist

1. Vá em **EQ** no menu lateral.
2. Selecione o canal que deseja ajustar.
3. Arraste os pontos para ajustar graves, médios e agudos.
4. Use **Auto-EQ** para correção automática.

## Auto-EQ (Recomendado)

1. Meça o espectro da sala (microfone USB + RT60).
2. Vá em **Auto-EQ**.
3. Clique em **Calcular Correção**.
4. Revise e aplique.
