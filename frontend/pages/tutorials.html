Autenticação & Cadastro do Templo

Login, registro e configuração inicial do templo

0/4 ▼
  1. 1. Abrir o App

    Ao iniciar, o sistema verifica se há sessão ativa no navegador. Se estiver logado, vai direto ao Dashboard.

  2. 2. Login ou Cadastro

    Faça login na página de autenticação. Se for novo, crie sua conta e registre as dimensões do templo (comprimento, largura, altura) — essenciais para os cálculos acústicos.

  3. 3. Credenciais Validadas

    Servidor Node valida as credenciais (bcrypt) e armazena em SQLite. O token JWT é entregue como cookie HttpOnly + SameSite=Strict, inacessível ao JavaScript (mitiga XSS).

  4. 4. Dashboard Liberado

    Após login bem-sucedido, você acessa o Dashboard com métricas ao vivo de SPL, RT60 e status do mixer.

Mixer & Controle da Mesa

Conecte e controle a Soundcraft Ui24R com presets de voz IA

0/4 ▼
  1. 1. Conectar à Mesa

    Acesse a página Sistemas e insira o IP da Soundcraft Ui24R. A conexão usa WebSocket nativo (v6.0.3+).

  2. 2. Selecionar Canal

    Escolha o canal ativo (1-24) na página de Canais de Entrada. Ajuste ganho, EQ, gate e compressor manualmente ou via IA.

  3. 3. Aplicar Preset de Voz IA

    Na página Presets de Voz, escolha Pregador/Fala, Smart Clean, Voz Masculina ou Feminina. O preset aplica EQ, HPF e compressor automaticamente.

  4. 4. Comandos via IA

    No Assistente IA, digite comandos como "aumente o volume do canal 3" ou "aplique HPF no canal 1". O sistema envia o comando ao mixer com confirmação humana.

Medir — SPL, RTA & Mapeamento

Medições acústicas em tempo real com calibração e grid espacial

0/5 ▼
  1. 1. Acessar Medição

    Na barra lateral, clique em Medir ou vá direto para o Analisador. O sistema tenta detectar o mixer via mDNS; se falhar, usa o microfone local como fallback.

  2. 2. Calibrar Microfone

    Faça upload de um arquivo .cal do fabricante ou inicie o ruído rosa. Ajuste ganho e ponderação (dBA/dBC).

  3. 3. Medir SPL ao Vivo

    Visualize o gráfico RTA (tempo real) e o medidor SPL digital. Escolha FAST (transientes) ou SLOW (média).

  4. 4. Mapear Pontos no Templo

    Caminhe pelo templo e clique nos pontos correspondentes no grid 2D para registrar a assinatura acústica de cada região.

  5. 5. Exportar para Análise

    Os pontos salvos na sessão podem ser enviados ao Assistente IA para recomendações ou visualizados no Mapa SPL em 3D.

Analisar — RT60, Heatmap & Benchmarking

Cálculos acústicos avançados com backend Python

0/4 ▼
  1. 1. Calcular RT60

    Na página Acústica, insira volume (m³) e área de superfície (m²) do templo. O backend Python calcula via Eyring/Schroeder com fallback Sabine local.

  2. 2. Heatmap de Dispersão

    Visualize o grid 3D de pressão sonora. O mapa interpola os pontos medidos para estimar cobertura, zonas de sombra e cancelamento de fase.

  3. 3. Benchmarking

    Compare medições de templo vazio vs templo cheio. O gráfico é atualizado via WebSocket sempre que uma nova medição é registrada.

  4. 4. Auto-EQ com Alvo

    Na página Auto-EQ, o computador da mesa gera uma curva de equalização corretiva baseada na medição RTA. Use o backend Python para PEQ + GEQ de 31 bandas.

Diagnóstico Técnico

Verificação de saúde do sistema, serviços e conectividade

0/4 ▼
  1. 1. Acessar Diagnóstico

    Vá para a página Diagnóstico pelo menu Sistema. Uma bateria de testes sintéticos é executada automaticamente ao carregar.

  2. 2. Verificar Serviços

    Três cartões mostram o status de: Node Server (socket, validações Zod, limites de canal), Python AI (Schroeder, TinyLlama), Frontend (AudioWorklet, cotas localStorage).

  3. 3. Testar Conexões

    Clique em "Testar AI" para disparar requisição manual ao backend Python, ou "Testar Server" para verificar o servidor Node. Logs são exibidos no console interativo.

  4. 4. Diagnóstico Preditivo

    O backend Python oferece diagnóstico preditivo de hardware via predictive_maintenance.py. Verifique o endpoint /hardware_diagnosis.
